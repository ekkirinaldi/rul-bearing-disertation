\chapter{Tautan Kode Implementasi dan Reproducibility}
\label{lamp:kode}

Seluruh kode implementasi dan konfigurasi eksperimen yang digunakan dalam
disertasi ini tersedia secara publik untuk mendukung
\emph{reproducibility}.
Berkas \emph{checkpoint} model tidak dilampirkan pada repositori karena
ukuran; berkas tersebut dapat dihasilkan ulang dengan menjalankan
skrip pelatihan yang disertakan.

\section{Repositori}
\label{lamp:kode_repo}

\begin{itemize}
  \item Repositori utama:
        \url{https://github.com/ekkirinaldi/rul-bearing-disertation}
  \item Lisensi: MIT (kode), CC-BY-4.0 (dokumentasi)
  \item Pencatatan revisi kode untuk Bab~V: setelah
        \texttt{git clone} / \texttt{git pull} pada salinan lokal,
        jalankan \texttt{git rev-parse HEAD} dan simpan keluarannya
        bersama \emph{log} pelatihan di
        \path{Mamba-xLSTM/results/runs/} agar setiap angka pada
        Bab~V dapat dirujuk ke objek \emph{commit} yang tepat.
\end{itemize}

\section{Cara Menjalankan}
\label{lamp:kode_run}

% Perintah mengikuti README repositori (subdirektori Mamba-xLSTM/).
% Font lebih kecil + baris dipatahkan agar tetap dalam tepi cetak ITB.
{\footnotesize
\begin{verbatim}
# Unduh dataset mentah ke akar repositori (sibling Mamba-xLSTM/)
U=https://dataset-bearing-rul.s3.\
ap-southeast-2.amazonaws.com
curl -fL -o data-bearing.zip \
  "$U/data-bearing/data-bearing.zip"
unzip -q data-bearing.zip && rm -f data-bearing.zip
mkdir -p data-bearing
curl -fL -o xtju-sy.zip \
  "$U/data-bearing/xtju-sy.zip"
unzip -q -o xtju-sy.zip -d data-bearing/ \
  && rm -f xtju-sy.zip

# Lingkungan Python (GPU: ikuti scripts/bootstrap_gpu_vps.sh di repositori)
cd Mamba-xLSTM
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -e \
  ".[mamba_pure,xlstm,interp]"

# Perbandingan algoritma (contoh: PHM2012 + XJTU-SY, satu model)
python scripts/run_algorithm_comparison.py \
  --datasets phm2012 xjtusy \
  --models mamba_xlstm_rul \
  --train configs/train/algorithm_comparison.yaml
\end{verbatim}
}

\section{Daftar Versi Pustaka}
\label{lamp:kode_versi}

Daftar dependensi inti dan rentang versi yang disyaratkan dicantumkan
pada berkas \path{Mamba-xLSTM/pyproject.toml} (tabel dependensi
proyek \texttt{mxlstm}).
Untuk merekam versi paket yang identik dengan lingkungan pelatihan
Bab~V, gunakan
keluaran \texttt{pip freeze} setelah instalasi pada mesin target dan
simpan bersama \emph{log} pelatihan di
\path{Mamba-xLSTM/results/runs/}.
