# Research Code and Results

This directory holds the code behind every number in Bab IV and Bab V, and the results those numbers came from. When the manuscript and a run disagree, the run is taken as correct and the manuscript is changed. Before editing a number in either place, find the run that produced it.

| Directory | What it holds | Used in |
|---|---|---|
| `notebooks/` | CWRU notebooks for the three diagnostic papers, plus scripts that redraw their figures into `notebooks/output/` | Bab IV, Lampiran E–G |
| `papers/` | The four published papers the dissertation builds on | Bab II, IV, V |
| `Mamba-xLSTM/` | Training, evaluation and interpretability pipeline for the RUL backbones and the Top-*k* SAE (Python package `mxlstm`) | Bab V, Lampiran A–B |
| `inference-engine/` | Web dashboard that streams recorded bearing data through the trained Mamba-xLSTM-Net | Lampiran D |
| `data-bearing/` | PHM2012, XJTU-SY, IMS, CWRU and the PT SKF export; kept on disk only, download steps in [docs/compute-setup.md](../docs/compute-setup.md) | all |

`Mamba-xLSTM/` and `data-bearing/` must stay side by side: the data configs point to `../data-bearing/…`.

## Diagnostic track (Bab IV)

Each notebook reproduces one paper end-to-end on a CPU:

- `Conference1_Classification_SVM_LR.ipynb`: SVM and LR with SHAP KernelExplainer
- `Conference2_Classification_Tree.ipynb`: DT, RF and XGBoost with SHAP TreeExplainer
- `Journal1_Fault Signature Maps.ipynb`: WDCNN with SHAP DeepExplainer and the Fault Signature Maps

The appendix figures are redrawn from the same experiments by `gen_confusion_matrices.py` (Lampiran E), `gen_tree_confusion_matrices.py` (Lampiran F) and `gen_fsm_figures.py` (Lampiran G). Their output is copied into `manuscript/assets/figures/lampE–lampG/`.

## Prognostic track (Bab V)

Everything under `Mamba-xLSTM/results/` that the chapters rely on is tracked:

| Path | Contents |
|---|---|
| `results/_comparison_configs/` | Merged configs of the comparison sweeps: the hyperparameters actually used for each model, dataset and seed (batch size, window, epochs). Read these before quoting a hyperparameter. |
| `results/reports/` | Cross-run HTML reports: the three-backbone comparisons per dataset and seed, the ablations, and the explainability reports |
| `results/bpfx_mapping/` | SAE→BPFx results for PHM2012 and XJTU-SY: correlations, hit rates, the feature 474 / BPFI scatter |
| `results/_chapter_assets/` | Diagrams, rendered equations and the BPFx figures in the form the chapters use them |
| `results/journal_q2/` | Follow-up experiments for the JETS paper: cross-architecture runs, negative controls, sparsity and threshold sweeps, statistics |
| `results/v1_initial/` | Reports from the first experiment round, kept for reference |

The per-run directories under `results/runs/<timestamp>_<run_id>/` hold `config.yaml`, `summary.json`, `hi_scaler.json`, test predictions and checkpoints. At 1.2 GB they are kept on disk and out of git. When a claim depends on a single run, for example the 36 HI features read from `hi_scaler.json`, check it there.

The Bab V figures that come straight from code are regenerated by `scripts/gen_hitrate_panel.py` and `scripts/gen_corr_scatter.py`. The first writes directly into `manuscript/assets/figures/bab5/`.

## Running

Environment setup, training commands and the report builder are in [Mamba-xLSTM/README.md](Mamba-xLSTM/README.md). Remote GPU runs are covered in [docs/compute-setup.md](../docs/compute-setup.md). The dashboard:

```bash
Mamba-xLSTM/.venv/bin/python -m pip install -r inference-engine/requirements.txt
./inference-engine/run.sh                      # http://localhost:8800
cd inference-engine && ../Mamba-xLSTM/.venv/bin/python scripts/smoke_test.py
```

Tests: `cd Mamba-xLSTM && .venv/bin/python -m pytest tests`.
