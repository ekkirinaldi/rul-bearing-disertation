Executive summary

{% if comparison %}

This report compares {{ comparison.left_label }} against {{ comparison.right_label }} using the same reporting pipeline, metric definitions, plots, and merged configuration dump. The goal is to make the model trade-off visible: accuracy, bias, training stability, and runtime are read together rather than as isolated numbers.

  • Primary accuracy metrics: lower RMSE, MAE, and loss are better; higher R² is better.
  • PHM score convention: the project phm_score is higher-is-better, while Liu / paper-style phm_score_paper is lower-is-better.
  • Figure reading order: first inspect aggregate metrics, then training curves, then per-bearing prediction and residual plots to separate general accuracy from systematic bias.
{% else %}

This report consolidates {{ runs|length }} RUL experiment run(s) into one dissertation-style artefact. It combines aggregate metrics, model-level diagnostics, train/validation dynamics, held-out bearing predictions, residual analysis, execution logs, and full merged configuration for reproducibility.

  • Rank models by test behavior, not validation alone: validation RMSE selects checkpoints, but held-out bearing plots show whether that checkpoint generalizes.
  • Use multiple metrics: RMSE emphasizes large mistakes, MAE shows typical absolute error, R² shows explained variance, and PHM score captures the asymmetric cost profile used in bearing prognostics.
  • Check runtime and parameters: a lower RMSE is only compelling if its training time and model size are acceptable for the intended research comparison.
