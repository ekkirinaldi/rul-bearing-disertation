# Archive

Material that is no longer edited, kept so that earlier versions of the work can be traced.

- `docx-port/`: the June 2026 conversion of the LaTeX manuscript into ITB Word chapters (Bab I–VI, Lampiran A–G, front matter, merged master) and the scripts that produced it. The V-series manuscript in `manuscript/` was edited on from this point, and several numbers here are older than the ones in V16, so do not quote from it. The LaTeX sources the scripts read were removed from the tree in September 2026 and are in the git history before that date.
- `notes/`: experiment design notes, the first draft of the Bab V results, the research design chart and the experiment report generated from the training runs.
- `local/`: seminar drafts, ITB reference documents and other files kept on disk only (not in git).
